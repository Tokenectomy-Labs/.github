## Kronumos CLI — Fix Bugs in 2 Commands

No long prompts. Run `/blast` to map impact across files, then `/fix` to diagnose failures, validate syntax locally, apply clean patches, and verify against your test suite.

### Quick Start

```bash
# Run via npx
npx kronumos

# Linux / macOS native binary
curl -fsSL https://dl.kronumos.com/install.sh | bash

# Windows PowerShell native binary
irm https://dl.kronumos.com/install.ps1 | iex
```

Or try directly in your browser at **[kronumos.com/chat](https://kronumos.com/chat)**.
